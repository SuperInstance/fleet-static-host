# fleet-static-host

One Cloudflare Worker, static assets, no moving parts. Serves the fleet's public shelf:

| Path | What |
|------|------|
| `/mist/` | **MIST — Tale of a Sheepdog Puppy** (playable Next.js static export, 1.4 MB) |
| `/ternary/` | **Ternary ROM** interactive visualizer (fetches `./data/*.json`, same-root) |
| `/papers/` | 7 SuperInstance research papers, markdown → styled HTML, KaTeX math |
| `/writings/` | 24 verbatim pieces from the agent-writings archive (chronicles, poetry, philosophy…) |
| `/` | Lobby page linking all four |

## Why Workers static assets (not Pages)

Workers static assets are served from Cloudflare's asset tier (free, no invocation
billing for asset hits), deploy in one command, and are custom-domain ready via
`wrangler` routes. No GitHub Pages dependency.

## Layout

```
public/            ← everything served (committed, so deploy needs no build step)
  mist/            ← copied verbatim from mist-game/out
  ternary/         ← copied verbatim from ternary-rom/web
  papers/          ← generated by build_site.py
  writings/        ← generated by build_site.py
  index.html, 404.html
build_site.py      ← regenerates papers/ + writings/ + root (python3-markdown required)
wrangler.jsonc     ← assets binding: { "assets": { "directory": "./public" } }
```

## Rebuild & redeploy

```sh
python3 build_site.py     # only needed when papers/writings change
npx wrangler deploy
```

Copy fresh game/ternary builds with `cp -r <src> public/<name>`.
